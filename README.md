# LocalCall v1.0 — Test Build

LocalCall is planned as a local communication app for nearby devices:
- Calls
- Texting
- File sharing
- Nearby/hotspot discovery
- QR pairing
- Diagnostics/testing
- Security/privacy controls
- Modern Android compatibility

Owner: KelvinLyon

This starter project contains the Android app shell and a first human-friendly UI. The networking, encrypted transport, audio calling, discovery, pairing, and transfer layers should be implemented and tested incrementally on real devices.
